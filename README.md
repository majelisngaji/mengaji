# Majelis Mengaji Android

Aplikasi Android untuk **Majelis Mengaji** yang terhubung dengan:

- https://mrobbie.com/majelis-ngaji/
- mode offline setelah konten tersinkron
- pembaruan konten otomatis dari website
- dukungan swipe halaman pada konten bacaan
- package Android: `com.mrobbie.majelismengaji`

Created by: mrobbie.com
